# 财富自由计算器 · 480 倍公式

单文件网页计算器：估算「严格财富自由」所需的本金门槛——资产扣除通胀后的实际收益，永久覆盖生活开销，并预留育儿、医疗、购房三类大额刚性支出。

![截图](docs/screenshot.jpg)

## 公式

```
W = 480X + K×N + M + H
```

| 项 | 含义 |
|---|---|
| **480X** | 日常开销本金：X 为家庭每月日常开销；480 = 年开销 12X ÷ 2.5% 实际收益率 |
| **K×N** | 育儿：N 个孩子 × 单娃 0–18 岁总预算（默认按新一线城市约 70 万） |
| **M** | 大病医疗储备（自费药、靶向药、长期护理） |
| **H** | 购房支出（剩余房贷本金，或置换/二套预算） |

实际收益率可在 1.5%–3.5% 间调节，乘数随之联动（2.0% → ×600，3.0% → ×400）。

## 使用

零依赖、零构建：克隆后**双击 `index.html`** 即可离线使用。

```bash
git clone https://github.com/FavorPan/financial-freedom-calculator.git
open wealth-freedom-calculator/index.html
```

## 假设与口径

- 名义收益 4%–4.5%：专业机构长期年化参考全国社保基金 7.39%（2000–2024）、企业年金 6.17%（2007–2024），散户到手扣 2–3 个百分点费用；长期通胀按 2%
- 资金须做股债等资产配置，全存定存则公式不成立
- 城市养育预算为按人均 GDP 对全国均值（约 58 万）的估算值，非报告原值
- 结果建议在测算值上再留 20–30% 缓冲
